# 다락방 업적

6개 업적: 다락방 입문, 첫 수익의 맛, 다시 봄날, 왕좌에 앉다, 꾸준함의 불꽃, 투자 기록가.

브리핑의 서버 일별 기록으로만 판정한다. 구성 유지 플러스 전환은 연속 날짜의 누적 수익률 0% 이하→0% 초과 변화가 필요하다. 챔피언은 2명 이상 참가한 기록에서만 판정한다. 연속 기록은 멤버의 포트폴리오 기록일이며 개인 로그인 횟수가 아니다. 없는 날짜를 채우지 않는다.

달성 결과는 기존 Supabase `attic_store`의 `achievement_v1:<memberId>:<achievementId>` 별도 키로 저장한다. 최초 저장 시 충돌 무시로 달성일을 보존한다. 기존 포트폴리오·PIN·브리핑 원본은 수정하지 않는다. 최초 기록부터 가장 먼저 확인된 달성일을 기록하며 2026-09-30 이전 이력은 소급하지 않는다. 업적 저장을 서버에서 재조회한 뒤 화면에 표시한다.

메인 업적 전당에서 멤버별 6개 업적을 요약하고, 멤버 상세 수집판에 조건·달성일·7일 연속/30일 누적 진행률을 표시한다. 달성 결과는 이후 가격 하락, 순위 변경, 보유 자산 삭제에도 유지한다. 업적은 투자 실력 인증이 아니다.

검증: 53개 테스트, TypeScript 검사, Vite 빌드.
