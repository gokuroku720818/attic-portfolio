# 다락방 브리핑

오늘(전날 기록 대비), 주간(최근 7일), 월간(최근 30일) 브리핑을 제공한다.

- 기존 Supabase `attic_store`에 `briefing_day_v1:YYYY-MM-DD` 키로 일별 기록을 저장한다. `main_state`는 수정하지 않는다.
- 저장 전 서버의 최신 포트폴리오를 다시 읽는다. PIN과 사자후는 기록하지 않는다.
- 사이트 접속 중 최초 실행, 자산 변화, 1분 주기, 새로고침 버튼으로 기록을 저장한다. 한국 날짜를 사용한다.
- 접속 없는 날은 기록이 없다. 별도 서버 스케줄러는 설치하지 않았다.
- 같은 날에는 마지막 확인 기록으로 갱신한다. 화면에서는 최근 90일 기록을 읽는다.
- 기준일 기록이 없는 주간/월간 브리핑은 기간 내 첫 기록부터 비교하며 부분 기간을 표시한다. 이전 기록이 없으면 변화 수치를 만들지 않는다.
- 멤버 누적 수익률 변화는 %p, 종목 가격 변화는 %로 구분한다. 입출금과 매매를 보정한 기간 투자수익률은 아니다.
- 보유 구성 변경을 표시하고 수정된 자산은 종목 가격 비교에서 제외한다.
- 공통 인기 종목은 회원별 중복을 제거한 현재 보유 인원이다.

검증: 43개 테스트 및 TypeScript/Vite 빌드 통과. GitHub Pages의 세 탭 전환, 기존 종목 링크 유지, Supabase 공유 기록 저장 완료 표시 확인.
