# 속도 및 안정성 개선

- 메인 JavaScript 빌드 크기: 497.94KB → 466.19KB(압축 전). 자산 관리, 멤버 상세, 자산 입력 화면을 사용할 때만 불러온다. 실제 체감 지연 시간 개선률을 측정한 수치는 아니다.
- 공유 원본 보완 조회는 5초→30초로 줄인다. Realtime 구독은 유지하고 숨겨진 화면의 주기 조회는 중단한다. 조회 요청 중복을 막고 복귀 시 다시 확인한다.
- 업적의 정기 확인은 15초→60초로 줄인다. 브리핑 조회는 짧은 캐시와 동시 요청 병합을 사용한다. 기록 내용이 그대로면 같은 날짜 서버 기록을 재저장하지 않는다. 저장 후 캐시는 무효화하며 이전 요청이 늦게 끝나 최신 캐시를 덮는 경우도 막는다.
- 자산·PIN·사자후 변경은 서버 최신 자료에 변경된 필드만 병합한다. 갱신 시각 조건으로 충돌을 확인하고 최대 3회 재시도한다. 같은 브라우저의 변경은 순서대로 저장한다. 공감 수는 증가량을 합산한다.
- 서버 저장 중/완료/실패 상태를 헤더에 표시한다. 저장 중에는 조회가 편집 화면을 덮지 않도록 한다.
- Supabase HTTP 요청에 15초 제한을 적용하고 호출자의 취소 신호를 유지한다. 로컬 캐시 저장 실패가 서버 갱신을 중단시키지 않도록 한다.
- 화면 오류나 배포 중 지연 로딩 파일 오류에는 재시도 화면을 표시한다.

검증: 62개 테스트 통과, TypeScript/Vite 빌드 통과, git diff --check 통과. 실제 금융 거래나 공개 메시지 등록을 테스트로 수행하지 않는다.
